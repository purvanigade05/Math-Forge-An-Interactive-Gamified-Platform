01. Permutations

A permutation is an arrangement of objects where order matters.

Factorial

n! = n × (n−1) × ... × 1

Formula

nPr = n! / (n−r)!

Example

5P3 = 5 × 4 × 3 = 60

Applications

  • Arrangement
  • Ranking
  • Passwords
  • Position assignment
  • Scheduling
ORDER MATTERS → PERMUTATION

02. Combinations

A combination represents a selection in which order does not matter.

Formula

nCr = n! / [r!(n−r)!]

Example

8C3 = 8! / (3!5!) = 56

Important Identity

nCr = nC(n−r)

Applications

  • Team selection
  • Subset selection
  • Probability
  • Feature selection
  • Test-case selection
ORDER DOES NOT MATTER → COMBINATION

03. Restricted Arrangements

Advanced problems may require objects to stay together, remain separated or occupy specific positions.

Block Method

[AB], C, D, E

Treat A and B as a single block when they must stay together.

Complement Method

Required = Total − Unwanted

Common Restrictions

  • Must be together
  • Cannot be together
  • No two adjacent
  • Fixed position
  • At least
  • At most

04. Recurrence Relations

A recurrence relation defines a sequence using one or more previously calculated terms.

aₙ = f(aₙ₋₁, aₙ₋₂, ...)

Example

a₀ = 2
aₙ = aₙ₋₁ + 3
a₁ = 5
a₂ = 8
a₃ = 11
a₄ = 14

Order

The order depends on the furthest previous term required by the relation.

05. Recurrence and Algorithms

Recurrence relations describe recursive and divide-and-conquer algorithms.

Example

T(n) = 2T(n/2) + n

Expansion

T(n) = 2T(n/2)+n
= 4T(n/4)+2n
= 8T(n/8)+3n

The total complexity is O(n log n) for this recurrence.

Applications

  • Merge Sort
  • Binary Search
  • Recursive algorithms
  • Complexity analysis
  • Dynamic programming

06. Problem-Solving Strategy

Step 1 — Understand

Identify exactly what the problem asks.

Step 2 — Identify the structure

Determine whether it involves arrangement, selection, restrictions or previous terms.

Step 3 — Select the method

Arrangement → Permutation
Selection → Combination
Previous terms → Recurrence

Step 4 — Calculate

Substitute values carefully and simplify.

Step 5 — Verify

Check restrictions and make sure cases are not counted twice.
