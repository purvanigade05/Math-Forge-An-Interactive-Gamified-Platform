## 🌟 What is Math Forge?

**Math Forge** is an interactive and gamified mathematical learning platform designed to make learning mathematics more engaging.

Instead of only reading theory, users can:

🧠 **Learn** mathematical concepts
🎯 **Solve** interactive questions
⚡ **Earn XP** for correct answers
🏆 **Unlock Achievements**
📊 **Analyse their performance**
📈 **Progress from Easy → Moderate → Difficult**
